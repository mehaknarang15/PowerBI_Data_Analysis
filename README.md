# 🔍 Attrition Analysis Dashboard

A Power BI dashboard project aimed at analyzing employee attrition within an organization using HR data. The project explores key attrition drivers like job satisfaction, job role, salary, age, education and years at company to uncover actionable insights for workforce retention.

---

## 📊 Project Objectives

- Understand the key factors influencing employee attrition.
- Identify at-risk employee groups based on attrition metrics.
- Present insights via intuitive, interactive Power BI visualizations.

---

## 📈 Dashboard Features

- Filters for Age, Department, Education, and Gender
- Attrition breakdown by Job Role, Satisfaction Scores, Years at company, etc.
- KPI cards and dynamic visuals for quick interpretation

---

## 📌 Key Insights

- **Job Satisfaction** and **Environment Satisfaction** are highly correlated with attrition.
- Employees with **lower salary** and **low job satisfaction** are more prone to leave.
- Attrition is **higher among younger employees** and those with **fewer years at company**.

---

## 🛠️ Tools & Technologies

- **Power BI** for dashboarding and data visualization
- **Excel/CSV** as data source for HR records
- **DAX** for calculated metrics
